# Code of conduct

OpenCADIrrigation is made by people who design irrigation, write code and translate it into many languages. To keep
the project a place where anyone can take part:

- Be respectful and patient, in any language. Many contributors write in a language that is not their own.
- Discuss the work, not the person. Criticism of code, designs, translations and ideas is welcome when it is
  specific and kind.
- No harassment, insults, discrimination, personal attacks or unwanted sexual attention, in public or in private.
- Do not publish other people's private information.
- Keep to the editorial rule of the repository ([CONTRIBUTING.md](CONTRIBUTING.md)): no competing product is named.

The maintainer may edit or remove comments, issues and contributions that break these rules, and may block whoever
keeps breaking them. To report a problem, open an issue asking for a private channel (without details), or use the
private report of the Security tab when it concerns someone's safety.

This code applies to the repository, its issues and pull requests, and to every space where someone represents the
project.
